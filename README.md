# NTL-GGM
Node-wise transfer learning for high-dimensional graphical models and precision matrix estimation

1. The root directory contains the main function for implementing NTL-GGM, together with all programs used in the simulation studies.
2. The folder "Trans-Glasso-implement-by-R" includes all codes for implementing the Trans-Glasso. 
3. The folder "real data analysis" contains all programs and corresponding results for the real-data analysis.
